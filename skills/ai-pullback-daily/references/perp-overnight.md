# 第二步之二：盘后 / 休市期间隐含变动【24/7 永续 · 纯观察节点，不改触发】

> **定位**：与「📐 补充观察·均线结构」同级——**这是观察节点，绝不改变 T1/T2/T3 触发判定与分桶结论**。T1/T2/T3 永远只用「最近一个完整交易日收盘价」计算。本节提供的是**现货收盘之后、下次开盘之前**这段时间的活报价。
>
> **为什么有用**：本任务在美东 17:30 左右运行（现货 16:00 已收盘约 1.5 小时），且**每个日历日都跑**（含周末/休市）。Hyperliquid `xyz` 池的股票永续 **24/7 不间断交易**，因此：
> ① **休市日/周末**——个股技术部分按规则冻结，这是唯一的活报价，能看出休市期间产业链在被重新定价还是没人动；
> ② **盘后**——当日盘后财报的市场反应会立刻反映在永续价上，比明天开盘早知道；
> ③ **开盘前**——隔夜消息的实时定价，提前知道跳空方向与幅度。
>
> **运行频率**：每个日历日都跑（与引爆点监控同频）。休市日**照常更新本节**——这不违反「休市不谎报新数据」，因为这是**另一个标的（永续合约）的真实成交价**，且全程标注为「隐含」，绝不写成现货收盘价。

**取数（一次 API 调用取全部，免费免 key）**：
```bash
curl -s -X POST https://api.hyperliquid.xyz/info \
  -H 'Content-Type: application/json' -d '{"type":"metaAndAssetCtxs","dex":"xyz"}' \
| jq -r '[.[0].universe, .[1]] | transpose | .[]
   | "\(.[0].name) mark=\(.[1].markPx) prevDay=\(.[1].prevDayPx) notionalOI=\((.[1].markPx|tonumber)*(.[1].openInterest|tonumber)) dayVlm=\(.[1].dayNtlVlm)"'
```
必须带 `"dex":"xyz"`。Hyperliquid **主池**的 `SPX` 是 SPX6900 迷因币（$0.34），不是标普500，取错池会得到完全错误的数字。

**监控池 → `xyz` 市场映射**（2026-07-27 实测，名义 OI = `markPx × openInterest`）：

| 分档                              | 标的（`xyz:` 前缀）                                                                              | 名义 OI 量级 |
|-----------------------------------|--------------------------------------------------------------------------------------------------|--------------|
| **主用**（OI ≥ $10M，读数可信）   | MU, SPCX, NVDA, GOOGL, DRAM, SNDK, TSLA, INTC, MRVL, AMD, AMZN                                   | $15M–$208M   |
| **薄盘·仅参考**（$3–10M，须标注） | TSM, RKLB, AVGO, ARM, LITE, BE                                                                   | $3.6M–$8.4M  |

| **未上架**（跳过，不要硬找替代）  | GFS, TTMI, MRAAY, ADI, TXN, COHR, GLW, AXTI, ALAB, AAOI, SOXX, ANET, VRT, CSCO, 0700.HK, 1810.HK | —            |

- **SK海力士务必用 `xyz:SKHX`**（$1,235.8 = 000660.KS 收盘 1,816,000 KRW ÷ USD/KRW 1468.6，吻合到 0.06%，OI ≈ $506M）。**`xyz:SKHY` 是另一个口径（比值 0.132），不可混用。**汇率用同池的 `xyz:KRW`。
- **上述分档是基线，不是定论**：每次运行**都要重算名义 OI**，按门槛现场分档。若某标的 OI 骤降到 $3M 以下，说明池子在迁移或停摆，该报价不可信、直接跳过。
- 其余标的均为 **USD 计价、与现货 1:1**（实测 NVDA/MU/SNDK/TSLA/GOOGL/INTC/AMD/TSM/MRVL/AMZN/DRAM/SPCX 比值均在 1.00–1.05 之间，差额即为休市期间的隐含变动）。**新增标的首次使用前必须做一次 1:1 核对**，比值偏离 0.9–1.1 区间即判定取错市场。

**计算口径**：`隐含变动% = (perp mark ÷ 该股最近完整交易日收盘价 − 1) × 100`。分母必须用第二步已确定的**同一个「数据日期」收盘价**，保证与全表横截面一致。

**大盘层**：同池的 `xyz:SP500`（标普500，指数点位 1:1，≈7,400）与 `xyz:XYZ100`（纳斯达克100，改名避商标，指数点位 1:1，≈28,000）——OI 分别约 $483M / $282M，非常充裕。两者对照 `^GSPC` / `^NDX` 收盘算隐含跳空，并计算**科技相对强弱 = XYZ100 隐含变动 − SP500 隐含变动**（正值 = 科技领涨大盘）。此值直接关系整条 AI 算力链的风险偏好，写入「📊 大盘与板块背景」。

**使用规则（硬约束）**：
1. **绝不改变分桶**。隐含变动不产生 T1/T2/T3 触发、不影响任何买入桶。
2. 若隐含变动会让某股**跨过** T1/T2 阈值，只能写成**预告**：「若明日以此价开盘，将触及 T2@$XXX」——**不得记为已触发**，不得计入「✅ 未触发」清单的变更。
3. **|隐含变动| ≥ 2%** 的标的才输出；≥ 5% 视为重大异动，须在风险提示明细单列并 WebSearch 查起因。
4. **财报联动**：带 ⚠️EARN 标签、且当日盘后已发布财报的标的，其隐含变动即为**财报反应**，必须点名并注明「财报已出，盘后 ±X.X%」；此时「等财报后」的建议应更新为「财报已出，等明日现货确认」。
5. **薄盘标的**一律加「（薄盘 $X.XM，仅参考）」后缀。
6. 取数失败（API 超时 / 返回空 / 该市场不存在）→ 整节写「本次未取到 24/7 永续数据」，**不影响其余所有部分**，不重试超过 2 次。
