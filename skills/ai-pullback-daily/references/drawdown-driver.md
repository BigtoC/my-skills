# 第二步之三：回调驱动源判定（折现率 vs AI论点）【核心逻辑 · 节奏调节器，不是闸门】

> **定位**：本框架的核心命题是区分「便宜了」和「坏掉了」。原有的回调性质三分法（个股独走 / 板块共振 / 大盘拖累）只回答「跌的**范围**有多大」，没回答「**是什么在跌它**」。补上驱动源维度后变四分法。
>
> **为什么必要**：表内标的多为长久期资产（ARM 预期PE~88、ALAB~68、TSLA 预期~145），10Y 上行 10bp 杀掉的估值与 AI 需求毫无关系。这类回调**基本面完好、只是折现率变了**，对 🟢/🔵 是质量最高的买点；而引爆点🔴 的回调是**多头逻辑破了**，回调是陷阱。**混淆这两者是本框架最贵的错误**——把折现率回调当论点破 → 错过最好的买点；把论点破当折现率回调 → 抄底套牢。
>
> **硬约束**：驱动源**只调节节奏（批次/仓位/加仓条件），绝不改变 T1/T2/T3 触发判定、绝不改变分桶**。它**不是第三个闸门**——已有质量闸门（步骤2）与论点闸门（步骤3），再加一个否决闸门会让报告永远停在「降级观察」，实质瘫痪框架。

**板块相对强弱定义（规则化）**：`相对强弱 = SMH 日涨跌幅 − QQQ 日涨跌幅`（pt）。≥ +1.5pt → 半导体显著强于大盘；≤ −1.5pt → **半导体显著弱于大盘**；其间 → 同步。

| 驱动源              | 判定条件（须全部满足）                                                                   | 性质                       | 对 🟢/🔵 的节奏含义                                                                                                                                                                                         |
|---------------------|------------------------------------------------------------------------------------------|----------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **① 折现率驱动**    | 🔺利率上行 **且** QQQ 下跌 **且** 相对强弱 ≥ −1.5pt（同步或仅略弱） **且** 引爆点 0 项🔴 | **估值杀，基本面未损**     | 回调质量最高，分桶与买入建议**照常执行**；但利率上行有惯性 → 首批仓位 1/3 降为 **1/4**、批次拉长留子弹，加仓条件改为「10Y 见顶回落（单日 ≤ −5bp 或近 5 日累计转负）**或** 回踩 50DMA 获支撑」。止损纪律不变 |
| **② AI论点驱动**    | （➖利率平稳 或 🔻利率下行） **且** 相对强弱 ≤ −1.5pt **且** 引爆点 ≥1 项🟡/🔴           | **多头逻辑走弱**           | 走原有论点闸门（步骤3）：🔴 一律降 👀观察；🟡 仓位与批次减半、更依赖 T3 确认                                                                                                                                |
| **③ 双杀**          | 🔺利率上行 **且** 相对强弱 ≤ −1.5pt **且** 引爆点 ≥1 项🟡/🔴                             | 折现率与论点同时承压       | **最保守**：所有买入桶降 👀观察，等「**利率见顶 + 引爆点修复**」双确认再议                                                                                                                                  |
| **④ 个股/事件驱动** | ➖利率平稳 **且** QQQ/SMH 基本持平 **且** 仅个别标的异动                                 | 个股事件（财报/新闻/评级） | 原有逻辑不变，按 ⚠️EARN 与新闻起因处理                                                                                                                                                                      |
| **⚪ 无法判定**     | 10Y 数据缺失（⚪利率数据不足）                                                           | —                          | **不出驱动源结论**，按原有三分法执行，报告注明「缺利率数据、未判定驱动源」                                                                                                                                  |

- **多行同时符合时取更保守者**，优先顺序：③ 双杀 > ② AI论点驱动 > ① 折现率驱动 > ④ 个股事件。
- **与引爆点④的分工**：Fed 收紧引起的 HY 利差全面走阔归本节（①/③），**不归引爆点④**；仅 Neocloud 相对 HY 基准走阔才归④（见「引爆点④ 的 Fed 传导校准」）。
- **输出位置**：完整版写入「📊 大盘与板块背景」与「💡 总结与前瞻」；精简版并入 📊 之后的一句话定性行。
