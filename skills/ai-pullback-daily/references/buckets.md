# 触发条件、分桶规则与操作建议映射

> 本文件自 `AI算力产业链回调进场监控日更.md` **逐字迁移**，未改写。

# 第三步：触发条件
- T1 深度回调：收盘较 52 周高回撤 ≥ 15%（即 收盘 ≤ T1触发价 = 52周高×0.85）
- T2 短线回调：收盘较 20 日高回撤 ≥ 8%（即 收盘 ≤ T2触发价 = 20日高×0.92）
- T3 超卖：14 日 RSI ≤ 35（RSI 当前值即 T3 观察值）

# 第四步：分桶规则（产业评级 × 技术触发 × 论点闸门 × 节奏层）
步骤1 先按技术触发分桶（已补全 T1+T2 缺口）：
- 候选🚨重点买入 = (T1+T3) 且 价≥200DMA
- 候选⚡轻仓试探 = (T2+T3) 或 **(T1+T2，无T3)** 或 (仅T2)
- 候选👀观察 = (仅T1) 或 (仅T3) 或 (T1+T3但<200DMA) 或 (任意触发 + 财报≤7交易日)
- **未进任何桶（未触发）= T1/T2/T3 全否**：不建仓，但须在「✅ 未触发」清单中列出（见输出结构），不静默丢弃。

> 说明：T1+T2（无 T3）= 同时深回撤且短线回撤、但尚未超卖，归⚡轻仓试探。

步骤2 再用产业评级闸门覆盖（关键）：🟢/🔵 保持步骤1的桶；🟡/🔴 无论触发什么，一律强制降到👀观察，并加「⚠️基本面弱」标签 + 一句「回调≠机会，价值陷阱风险」。同一只股票只进最高优先级桶。未触发任何条件的不进任何桶（不强行触发），列入「✅ 未触发」清单。

**步骤3（宏观闸门·覆盖前两步）**：读取「引爆点监控」汇总裁决——
- 若 **≥1 项 🔴**：本日**所有** 🚨重点买入 / ⚡轻仓试探 **强制降级为 👀观察**（加标签「⚠️论点受损」+ 一句「回调≠机会，产业链结构性风险」），并在两版顶部挂醒目横幅注明触发的引爆点。个股仍可留在观察桶供跟踪，但明确「暂不建议抄底、等论点信号修复或周线企稳」。
- 若 **≥2 项 🟡（无🔴）**：保留步骤1/2 的分桶，但在总结与相关个股建议前加「论点转弱、节奏保守」提示（首批仓位减半、更依赖 T3 确认）。
- 个股 🟡/🔴 价值陷阱闸门（步骤2）与本宏观闸门（步骤3）叠加，**取更保守者**。

**步骤4（节奏层·不改分桶）**：读取「第二步之三·回调驱动源判定」与 ⚠️FOMC / ⚠️MACRO 标签——**不改变任何标的所属的桶**，只调整桶内建议的仓位、批次与等待条件（见「操作建议映射」的 FOMC/宏观事件叠加与驱动源叠加）。
- **防误判红线**：若判定为 **① 折现率驱动** 且引爆点 0 项🔴，则大盘/板块的普遍下跌**不构成论点受损**，**不得据此降级买入桶**——这恰恰是回调最可能是机会的情形（基本面未损、只是折现率变了）。
- 反之，若判定为 **③ 双杀**，即使引爆点尚无🔴，也按最保守处理（全体买入桶降 👀观察）。

# 风险标签
⚠️EARN：距下次财报≤7个交易日；⚠️<200DMA；⚠️<50DMA；📈放量：日量≥1.5×20日均量；⚠️基本面弱：评级🟡/🔴（触发时强制加）；⚠️论点受损：引爆点出现🔴时全体买入桶加此标签；🔻空头排列/破MA60：当 MA5<MA10<MA20<MA60，或价跌破 MA60 时标注，提示短中期趋势转弱；**⚠️FOMC：距 FOMC 决议 ≤2 个交易日，或决议日当天/次日**（全体标的通用，非个股属性）；**⚠️MACRO：CPI / PCE / 非农 发布前 1 个交易日**（仅标注，不改建议）。

# 操作建议映射（完整版用·已融合评级）
🟢/🔵+T1+T3+价≥200DMA → 重点买入，分2-3批（首批1/3，回踩50DMA加，破位减）；🟢/🔵+T1+T3+价<200DMA → 暂不抄底，等周线企稳或RSI背离；🟢/🔵+T1+T2(无T3) → 轻仓试探(≤1/3)，止损放20日低点，等T3或量能再加；🟢/🔵+仅T1 → 观察，等T3或量能；🟢/🔵+T2+T3 → 轻仓试探(≤1/3)，止损放20日低点；🟢/🔵+仅T2 → 轻仓试探，回踩50DMA再加；🟢/🔵+仅T3 → 左侧底仓≤1/4，止损-7%；🟡/🔴+任意触发 → 仅观察，不建议抄底(价值陷阱)；任意+⚠️EARN → 默认建议前加「等财报后」。
**论点闸门叠加（最高优先级）**：当引爆点 ≥1 项 🔴（⚠️论点受损）→ 无视上面所有买入类建议，一律改为「暂不抄底，等论点信号修复/周线企稳」；≥2 项 🟡 → 上述建议的仓位与批次全部减半、更依赖 T3 确认。

**FOMC / 宏观事件叠加（只改节奏与时序，不改分桶）**：
- 任意 + **⚠️FOMC（决议前 ≤2 交易日）** → 默认建议前加「**等 FOMC 决议后**」，与 ⚠️EARN 同构（不在已知的高波动事件前把子弹打完）。
- **决议日当天/次日** → 波动放大，**T3 超卖信号可靠性下降**（可能是事件噪音而非真超卖）→ 首批仓位减半，且要求次日现货确认（不追当日盘中）。
- 任意 + **⚠️MACRO** → 仅在建议后附「（CPI/PCE/非农 前夜，注意波动）」，**不降级、不减仓**。
- **⚠️EARN 与 ⚠️FOMC 同时出现** → 取更晚的事件为等待条件（如「等财报与 FOMC 均落地后」）。

**驱动源叠加（见第二步之三，节奏调节器）**：① 折现率驱动 → 建议照常，首批 1/3 改 **1/4**、加仓条件改为「10Y 见顶回落或回踩 50DMA 获支撑」；② AI论点驱动 → 并入论点闸门处理；③ 双杀 → 一律「暂不抄底，等利率见顶 + 引爆点修复双确认」；④ 个股事件 / ⚪ 无法判定 → 建议不变。**驱动源与论点闸门、质量闸门叠加时一律取最保守者。**

**均线结构精修（叠加在上述建议之上，仅🟢/🔵适用）**：
- 多头排列(MA5>MA10>MA20>MA60) 且 回踩 MA20/MA50 获支撑 → 结构健康，按既定建议正常执行，可略提优先级。
- 价跌破 MA5/10/20 但仍站 MA60 → 上升趋势中的深回踩，先观察能否在 MA60 上方企稳，首批仓位更轻(≤1/4)。
- 空头排列 或 价跌破 MA60 → 短中期趋势走弱，降低优先级 / 缩小仓位，或等周线企稳再议。
