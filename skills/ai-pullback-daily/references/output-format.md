# 全局规则
所有数据可追溯（WebSearch 取数逐点附 URL，yfinance 补算项注明本地计算，计算口径见第二步指标定义）；横截面所有标的对齐同一数据日期；无触发不强行触发，宁可空报告；**未触发标的不再静默丢弃，须在精简版「✅未触发」行与完整版「✅未触发个股」表中列出**；精简版与完整版数据严格一致（同一次取数）；基本面用第一步静态表，技术面用第二步每日取数，二者交叉得结论；MA5/10/20/60 仅作观察与建议精修，不作硬触发；**T1触发价/T2触发价仅为阈值展示（由 52周高/20日高 换算），不改变 T1/T2/T3 触发与分桶逻辑；RSI 字段同时充当 T3 当前观察值**；仅基于技术信号+产业质量框架，不构成投资建议。
**引爆点专项规则**：① 引爆点监控每个日历日都运行（含周末/休市日），5 项状态以 WebSearch 取数、逐项附 URL、缺数据记⚪不臆测；② 其汇总裁决通过第四步·步骤3 宏观闸门影响分桶（≥1🔴→全体买入桶暂停降级观察；≥2🟡→节奏减半）；③ 引爆点是慢-中变量，重点在「状态是否跨档变化」，无需每天有新数字。
**休市日规则**：个股技术数据只在完整交易日更新；休市/周末沿用最近完整交易日并明确标注，**绝不谎报新收盘数据或制造新触发**；按日历日更新的只有**引爆点监控**、**第二步之二「24/7 永续隐含变动」**，以及**「宏观利率背景」中的 FOMC 日历/隐含概率/政策倾向**（属事件日历与慢变量；但 10Y/DXY 的日变动仍沿用最近完整交易日并标注）。后者在休市日是唯一的活报价，但必须全程标注为「隐含」、注明是永续合约价而非现货收盘价，**不得写入任何以「收盘」为名的字段，不得据此判定新触发**。

**24/7 永续专项规则**：① 每个日历日都跑（含休市），与引爆点同频；② **纯观察节点，绝不改变 T1/T2/T3 触发与分桶结论**，跨阈值只能写成「若明日以此价开盘将触及 XX」的预告；③ 必须带 `"dex":"xyz"`（主池 `SPX` 是 SPX6900 迷因币），SK海力士用 `xyz:SKHX` 不用 `SKHY`；④ 每次重算名义 OI 分档，< $3M 直接跳过、$3–10M 标「薄盘·仅参考」；⑤ 新增标的首次使用须做 1:1 现货核对，比值偏离 0.9–1.1 即判定取错市场；⑥ 取数失败最多重试 2 次，失败则整节标注未取到，不影响其余部分。

**Neocloud 信用层专项规则（第二步之四）**：① 每个日历日都跑，与引爆点同频；指数/曲线为官方日频数据，休市日沿用最近发布值**并标注数据日**（不算谎报新数据）。② **引爆点④ 的状态只由脚本产出**，日报不另行人工判读、不得与脚本结论冲突；人工只负责把 WebSearch 取到的债券报价/一级市场条款喂进 `neocloud_bonds.json`。③ **L2 项目层 / L4 上游传染 → 论点闸门（步骤3）；L1 公司层 / L3 宏观确认 → 节奏层（步骤4）**。**L1/L3 单独走阔，不得降级任何买入桶**——这与「① 折现率驱动不得降桶」是同一条红线，混淆两者是本框架最贵的错误。④ 报价 `as_of` 超过 5 天判⚪、不参与触发；⚪ 不参与升档；缺 HY 基准或缺 neocloud 利差时④封顶🟡。⑤ 转债利差含期权价值、EUR 债无美债对标 → 一律「仅参考」，不参与判定。⑥ **不臆测利差**：脚本取不到就写未取到，不用 HYG/JNK 代替个股债券利差（两者已脱钩），不用指数 OAS 反推个股利差。⑦ 阈值集中在脚本 `TH` 字典，**校准阈值只改脚本一处**，文档表格随之同步。⑧ 每次输出保留「已知数据局限」五项声明，尤其**无实时 CDS 是本层最大盲区**。

**宏观利率 / FOMC 专项规则**：① 「宏观利率背景」每个完整交易日都取（10Y/2Y/2s10s/DXY/HY 基准），FOMC 日历与隐含概率**每次运行重新确认、不得沿用**；② **只描述状态，严禁预测利率路径**——不写「我认为会降息/加息」，只写市场隐含概率与官方日历；③ **驱动源判定与 ⚠️FOMC 标签只调节节奏（仓位/批次/等待条件），绝不改变 T1/T2/T3 触发与分桶**，不构成第三个否决闸门；④ **折现率驱动 ≠ 论点受损**：利率上行造成的板块普跌，在引爆点 0🔴 时不得降级买入桶；⑤ Fed 收紧引起的 HY 利差全面走阔归驱动源处理，**不得计入引爆点④**（须过相对 HY 基准检验）；⑥ 10Y 或 FOMC 日历取不到时记⚪，驱动源写「未判定」、按原有三分法执行，**不臆测**；⑦ 休市日/周末：FOMC 日历与政策倾向可按日历日更新（属慢变量与事件日历），但 10Y/DXY **日变动沿用最近完整交易日**并标注，不得谎报新数据。

# 静默/精简条件（本监控每日运行，完整版始终生成）
本监控**每个日历日都运行**（含周末/休市日），完整版始终生成；「引爆点监控」与「引爆点状态行」、以及「💵 利率行」、「**💳 信用④行**」**任何情况下都输出**（💵 行在休市日沿用最近完整交易日并标注；💳 行休市日沿用最近发布的指数值并标注数据日）。仅**个股技术部分**可在以下条件转安静：
- 若「大盘当日涨幅>1.5% 且 无任何个股触发 且 引爆点无🔴、无新增🟡」→ 精简版个股部分可只输出「✅ 今日个股无触发」（30字内），但**引爆点状态行仍照常输出**（此情形下所有标的均为未触发，「✅ 未触发」清单可合并进该行、不必重复罗列全部代码）。
- **休市/周末** → 精简版个股各桶沿用最近完整交易日、注明「美股休市，个股无新增触发」；引爆点状态行为当日最新，照常推送。**「🌙 盘后隐含」行在休市日必出**（这是当日唯一的活报价）。
- 上述任一安静情形下，若有 **|隐含变动| ≥ 2%** 的标的，「🌙 盘后隐含」行仍照常输出，不被安静规则省略。
- **强制完整推送**：只要「任一引爆点 🔴，或较上次新增🟡」→ 一律完整推送，不适用上面的精简/安静规则，且精简版顶部必须含🚨论点告警横幅。**同样强制完整推送的情形**：① 处于 FOMC 窗口（距决议 ≤2 交易日，或决议日当天/次日）；② 驱动源判定为 **③双杀**；③ 10Y 单日变动 |≥15bp|（利率大幅异动）；④ **信用层 L2 项目层由🟢跨档转🟡/🔴**（投资级租户项目债走阔＝主题指标本身松动，即使④汇总仍为🟡也须完整推送）；⑤ **信用层 L4 由🟢转🟡/🔴**（上游传染，最终裁决层）。此五种情形精简版必须含「📅 事件」行、驱动源结论，或「💳 信用④」行的跨档说明。
