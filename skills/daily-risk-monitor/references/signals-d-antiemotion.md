# E. 抗情绪层（信号 19–22 · 服务目标 1）

> **这四个信号回答同一个问题：今天这跌，正不正常？**
> 它们不预测未来，只提供**参照系**。大跌当天，先看完这四个再看别的。

### 19. 波动率归一化跌幅（σ 倍数）——**最重要的抗情绪工具**
- **计算**：`单日1σ = 20日已实现波动率(年化) ÷ √252`；`σ倍数 = |当日涨跌%| ÷ 单日1σ`
- **分档**：<2σ = 正常波动｜2–3σ = 留意｜**≥3σ = 真异常，值得查原因**
- **SPX 与 BTC 分开算**（波动率差 2–3 倍，不能共用标尺）
- **实测基线 2026-08-07**：SPX RV20 = **14.4% → 单日 1σ = 0.91%**；BTC RV20 = **20.7% → 单日 1σ = 1.30%**
- 📖 **大白话**：**绝对跌幅是最会骗人的数字。** 同样是 −2%：如果市场很平静（1σ = 0.66%），−2% 是 **3σ 的大事**；但如果波动率涨到 30%，1σ = 1.9%，−2% 就只是 **1σ 的日常**。你的情绪只认「−2%」这三个字，这个指标帮你换算成「这在当前环境算大还是算小」。
- ⚠️ **别当概率读**：市场是肥尾的，3σ 出现的频率远高于常态分布的预测。它是**相对标尺，不是概率**。

### 20. VRP（恐慌溢价）= VIX − 20日已实现波动率
- **触发**：**<0（转负）= 恐慌是真的**（实际波动已超过期权定价）｜**>15 = 恐慌过头**（保险费远贵于实际风险）
- **实测基线 2026-08-07**：14.90 − 14.4 = **+0.5**⚠️ ——**已经贴着零轴，比 7 月的 +7.2 大幅压缩**，是目前 30 个信号里最接近触发的一个。实际波动率追上了期权定价，缓冲垫几乎没有了。
- 📖 **大白话**：VIX 是「大家为未来买保险付的价钱」，已实现波动率是「实际上到底晃了多少」。**两者的差 = 恐慌溢价**。差很大 = 大家吓过头了（历史上常是买点而非卖点）；**差转负 = 实际波动已经超过大家的预期，恐慌不是想像出来的**，这时候才该认真。

### 21. 跨资产同步性（避险资产有没有在涨）
- **看什么**：当日 `SPY` / `TLT`（美债）/ `GLD`（黄金）/ `UUP`（美元）
- **仅在 SPY 单日跌 >1% 时判定**，否则标「不适用」
- **判定**：
  - 🟢 **股跌、债金涨** = 正常 risk-off 轮动（钱在换避风港，市场功能正常）
  - 🔴 **股债金同跌** = **无差别抛售换现金**（2020/3、2022/9 那种流动性事件）→ **计为 Tier 1 触发**
- 📖 **大白话**：正常的害怕，是把钱从股票搬去债券和黄金——那是**换位置**。真正的危险，是**连债券和黄金也在被卖**，那代表有人在被追缴保证金、必须无差别变现任何能卖的东西。**这是现有其它 29 个信号都看不到的维度**，也是区分「大家在避险」和「有人在爆」的关键。

### 22. 下跌广度（等权 vs 市值权）
- **计算**：`RSP 当日% − SPY 当日%`（RSP = 标普500等权 ETF）
- **判定**：|差| <0.5pt = 广度一致（普跌或普涨）｜RSP 明显更差 = **真·普跌**｜RSP 明显更好 = 只是巨头在拖
- **实测基线 2026-08-07**：RSP +0.69% − SPY +0.61% = **+0.08pt（广度一致，健康普涨）**
- 📖 **大白话**：SPY 按市值加权，前十大占三成以上，所以它涨跌很容易被几只巨头绑架。RSP 是 500 家每家一样权重。**两者一比就知道：是 500 家一起在跌（真的出事），还是只有几只巨头在跌（个股事件）。** 这比信号 2 更即时——信号 2 看的是存量（多少家在均线上），这个看的是当天的流量。
