## 🚨 数据暂缺的计数规则（不可省略）

> 📖 **为什么需要这条**：`❌ 未触发` 和 `⚪️ 无法判定` 是**完全不同的两件事**——一个是「查过了，安全」，一个是「不知道」。如果抓不到就填 ❌，等于把「不知道」静默地记成「安全」，**而这正好发生在最难抓、也最容易在市场转折时出问题的两项上（第 6、第 7 项）**。

- **⚪️ 项一律不计入触发数，也不计入分母。** 写法是「**今日共 X / N 项触发（M 项数据暂缺）**」，N = 7 − M。
- **必须同时给出最坏情况**：「若暂缺的 M 项全部触发，计数将达 X+M」——并说明那会不会跨过警戒升级（≥2）或分批门槛。
- **⚪️ 项 ≥3 时**，报告必须在决策层那一行加注「**本日触发计数可信度低（仅 N 项可判定）**」，战略基准**维持昨日档位不变**，不因计数下降而回补仓位。
- **绝不允许**因为「其余几项都很安全」就推断暂缺项也安全。

- 表格下方必须写：**「今日共 X / N 项触发（M 项数据暂缺）」**

## 「停止加仓」的准确定义（两条轨道共用）

> 📖 **为什么要写死**：「停止加仓」听起来像不用做事，其实是一个**主动动作**——它要求你把本来会自动流进市场的钱拦下来。不写清楚，最容易发生的事是「我没有主动买啊」，但定投照扣、股息照再投、现金照买，仓位其实一直在涨。

**「停止加仓」= 下列全部停止**，直到恢复条件成立：

| 项目                                           | 处置                                                       |
|------------------------------------------------|------------------------------------------------------------|
| **定期定额 / 自动扣款**                        | **暂停**（这是最容易漏掉的一项，因为它不需要你按任何按钮） |
| **股息、利息再投资**                           | 改为**留现金**，不自动买回                                 |
| **新增资金**（薪水、奖金、卖出其他资产的回款） | **停在现金 / 货币基金**，不进场                            |
| **「逢低加仓」**                               | **禁止**。下跌本身不构成加仓理由——规则没说加，就是不加     |
| **再平衡买入端**                               | 只做卖出端再平衡，不做买入端                               |

**「停止加仓」≠ 减仓。** 已有仓位**完全不动**，不卖出、不调整。它只关闭「往里搬东西」这个方向。

**触发场景（任一）**：战略层 T=1 且估值环境 🔴｜战略层 T=2 且估值 🟢/🟡｜战术层 🟡 减速。

## 最终动作

```
最终目标仓位 = 战略基准 × 战术系数
```

**每份报告必须明写这三个数**，例如：
> 战略基准 100%（7 项触发 0 项，估值 🔴）× 战术系数 1.00（🟢 持有）= **最终目标仓位 100%**

## 恢复条件（同样是规则，不是感觉）

- **战术层** 🔴/🟡 → 🟢：**SPX 重新站上 200DMA 且连续 5 个交易日站稳，且 200DMA 斜率转正。**
- **战略层** 回补：**7 项硬阈值触发数回落至 ≤1 且维持满 2 周**，才逐档往上回补一级（不可一次补满）。

（没有恢复规则的减仓规则等于永久空仓——这条和减仓条件一样重要。**处在非满仓状态时，每次都要报告「距离恢复还差什么」。**）

## 这套规则的代价（每次战术层进入 🔴 或战略基准 ≤70% 时必须复述一遍）

- **战术层每轮大跌会先扛 8–12% 才降曝险**——它不抓顶部，只确认机制转折
- **震荡市会被假讯号洗**，可能一年 1–2 次卖在阶段低点、错过后续反弹
- **战略层会太早减仓**——估值极端可以持续数年，分批止盈很可能少赚一大段
- **换来的是不会坐完整个熊市**

**双条件设计的理由**：只看价格跌破 200DMA 会被反复洗——加上「均线斜率也转负」这个慢变量做二次确认，代价是晚几天，好处是过滤掉绝大多数假突破。
