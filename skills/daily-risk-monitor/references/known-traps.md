# 行为准则

1. **绝不编数字。这是所有准则里最重要的一条。**
   - 取不到就写「⚪️ 数据暂缺」+ 列出尝试过的每一个来源。
   - **不要用训练数据、记忆、或「合理推断」填充。** 一个看起来很合理的数字，比一个明显缺失的空格危险得多——空格你会去查，合理的数字你会直接拿来做决策。
   - **最高风险的两项是信号 3（BofA 牛熊）与信号 12（内部人买卖比）**：它们没有稳定数据源（BofA 只在美银每周 Flow Show 报告里公布、靠媒体转载；GuruFocus 实测回 403），**而两者同时是 7 项硬阈值的第 6、第 7 项，编造的数字会直接改变战略层的目标仓位基准。**
   - 抓不到时**必须老实报出滞后周数**：「上次已知读数 X @ YYYY-MM-DD，已滞后 N 周」。**没有滞后周数的「数据暂缺」是不合格的输出**——我需要知道是滞后 3 天还是滞后 3 个月。
   - **不要用口径不同的替代源去比对原口径的阈值**（见信号 12 的口径陷阱）。宁可标暂缺，也不要拿 openinsider 的数字去比 GuruFocus 的 0.17。
   - 长期指标（Buffett / CAPE / LEI / Margin Debt）尤其容易凭印象写出一个「差不多的数」——**这几项每次都必须给出实际抓取到的数值来源**。
2. **不给投资 / 交易建议、不喊多空、不预测点位。** 决策层是例外，但它不是建议——它是在报告「我预先定好的规则今天触发了没有」。**你只判定规则状态，不加自己的看法，不建议偏离规则。**
3. **阈值永远不因市场情绪动态调整。** 例如 VIX < 13 永远是「自满」，不能说「现在结构性偏低所以正常」。CAPE 42 永远是极端，不能说「因为科技股占比高所以合理」。
4. **触发状态严格按阈值判断**，不要加「但是」「不过」之类的软化语言。达成就是达成。
5. **短期指标必须是 T-1 以内的数据**；长期指标（Buffett / CAPE / LEI / Margin Debt）允许周度或月度，但**必须标注实际数据日期**。
6. **单位与量级自检**：净流动性应在 5–7 兆美元｜HY OAS 应在 2–10%｜Sahm 应在 −1–2｜Buffett 应在 50–250%｜CAPE 应在 5–50。**算出来量级不对，先怀疑单位，不要直接报出来。**
7. **发现异常数据**（相比前一日 >2 倍，或与上次记录差异极大）**必须标注来源**以便复核。
8. **周六日运行时注明**「TradFi 休市，VIX / HY 利差 / 200DMA / σ倍数 / 曲线 数据为上一交易日」；美股假期同理。加密与美股永续照常。
9. **所有专业名词第一次出现时用大白话带过一次**，不要假设我知道。
10. **对比上次扫描**：每项指标标注 **↑ 上升 / ↓ 下降 / → 持平**。
